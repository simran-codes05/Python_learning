-- Password Generator

A simple Python-based Password Generator that creates random passwords using letters, numbers, and symbols. Users can customize the length and composition of their passwords by choosing how many letters, numbers, and symbols they want.

-- Features
Generate random passwords.
Choose the number of letters in your password.
Choose the number of numbers in your password.
Choose the number of symbols in your password.
Supports both uppercase and lowercase letters.
Shuffles all characters to create a random password.

-- Technologies Used
Python 3
Random Module (built-in Python library)

How many letters you want in your password? 5
How many numbers you want in your password? 3
How many symbols you want in your password? 2

Output:
aG7$k2#mP5

Note: The generated password will be different each time.
