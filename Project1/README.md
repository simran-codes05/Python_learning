Rock Paper Scissors Game 
-- Project Description

This is a simple Rock Paper Scissors game built using Python. The user plays against the computer, which randomly selects Rock, Paper, or Scissors. The program compares both choices and determines who is the winner.

This project is beginner-friendly and helps practice Python fundamentals such as conditional statements, user input, and the random module.

-- Technologies Used
Python 3
random module

-- Game Rules

Choice	Number
Rock       0
Paper      1
Scissors   2

Rock beats Scissors.
Scissors beats Paper.
Paper beats Rock.
If both choices are the same, the game ends in a tie.

-- Example Output:
text
Enter your choice : 0
Computer choice : 2
You win!

Note: The computer's choice is generated randomly, so the output may vary each time.

-- Features
Play against the computer.
Random computer selection.
Automatic winner determination.
Input validation for invalid choices.
Tie detection.
