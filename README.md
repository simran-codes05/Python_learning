-- 3. FizzBuzz Program
A classic beginner programming challenge that prints numbers in a sequence with the following rules:
Print Fizz for multiples of 3.
Print Buzz for multiples of 5.
Print FizzBuzz for multiples of both 3 and 5.
Print the number if none of the conditions match.

Concepts used:
for loops
if-elif-else statements
Modulo operator (%)
Conditional logic
